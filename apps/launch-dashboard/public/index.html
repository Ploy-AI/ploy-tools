Try your own data privately

  1. Open a Notion view you are allowed to access. Apply the Ploy 2.0 filter you want.
  2. Export the view as CSV, then import the unzipped CSV here. An exported view may include more rows than its visible filter; check the exported file.
  3. Filter and explore. File contents stay in this tab’s memory; they are not uploaded, saved, or shared with other viewers.

Reload or choose “Clear local data” to discard it. Screen sharing can still expose what you view.

Supported columns

Item (or Name/title), Owner (or Assigned to), Status, Priority, Launch blocker, Category, Notes, URL. Multiple owners can be comma-separated. Launch blockers are explicit; priority alone never marks a blocker.

JSON accepts an array or { "snapshotAt": "ISO timestamp", "items": [...] }. CSV imports show import time, not the unknown source snapshot time. Original links are available only when the export includes a valid HTTPS Notion URL.

No live refresh, production access, analytics, or Notion writes. Counts describe imported rows only, not a launch verdict.
